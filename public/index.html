Six modes · reference

These cards explain documented behavior. The app records actual reported modes, attempts, callback decisions and file state.

default

No mode-based approval. Unapproved actions can reach canUseTool.

dontAsk

Deny actions that would prompt. Pre-approved and safe built-in actions may still run.

acceptEdits

Approve eligible file operations within the working-directory scope.

plan

Explore and plan; file writes are not auto-approved, even by allow entries.

auto

A classifier can review eligible actions. A successful file write does not prove a classifier call.

bypassPermissions

Broad automatic approval with an explicit TypeScript opt-in; earlier rules and hooks still apply.
