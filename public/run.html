Configure and run the app.

Install the SDK, configure your key and run the classroom comparisons.

Application labWhat you will learnHow to runArchitecture & workflowCode walkthrough
01

Prerequisites

Install Node.js 24 or later and ensure API credit plus model access. On Windows configure Git Bash if required by the SDK. Python is needed only to regenerate student HTML.

node --version
npm --version
02

Install and create your .env file

From presentations enter this app, install locked dependencies and preserve an existing .env. Enter your model key privately. No GitHub token or Managed Agents resource IDs are required.

cd .\agent-sdk\lesson29-permission-modes
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
03

Start the application

Keep the terminal running and open the printed URL. The fixed agent tasks run in disposable directories rather than the course source directory.

npm start
# http://127.0.0.1:3129
04

Compare explicit modes

Run the first six experiments and compare actual mode reports, Write attempts, callback counts and file contents. Auto is an observational case and does not expose a classifier trace.

npm run sample:env -- default
npm run sample:env -- dontAsk
npm run sample:env -- acceptEdits
npm run sample:env -- plan
npm run sample:env -- auto
npm run sample:env -- bypass
05

Review and switch on one Query

In the web app choose Plan → review → acceptEdits, run it, review the actual first result and click Approve or Reject. Approval invokes setPermissionMode on the existing query before a second message is released. For an explicitly pre-approved CLI demonstration use the flag below.

npm run sample:env -- plan-to-edit --approve-plan
06

Check deny and omitted behavior

Run the scoped deny under bypass, then omit permissionMode and inspect the actual reported starting mode. Do not assume an older slide’s default applies to this installed runtime.

npm run sample:env -- bypass-deny
npm run sample:env -- omitted
npm test

Your .env configuration

ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3129
# Windows if needed: CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe

Only your model key is required. Keep it local and restart after edits. Existing shell variables take precedence.

Troubleshooting

Use Node 24+, API credit and a supported model. Configure Git Bash on Windows if requested. If the port is occupied, use the printed existing-app URL or change PORT. In plan-to-edit mode, respond to the review panel while the run is active. Rejecting leaves edits disabled. For auto, inspect actual reported mode and any runtime diagnostic. A successful file write does not prove classifier review.
