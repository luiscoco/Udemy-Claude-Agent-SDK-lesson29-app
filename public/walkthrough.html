01

Version-aware omitted defaults

The supplied slide and some SDK type comments mention auto as a possible omitted default. Current official docs say Claude Code 2.1.302+ headless/Agent SDK runs start in default unless settings or an explicit option change it. This app disables ordinary setting sources and records the actual initialization mode.

02

Plan is not auto-approval

Current docs route file writes to the callback in plan mode even if a Write allow entry matches. The model may also choose not to attempt a write while planning; lack of an attempt is different from an SDK rejection. The live evidence must be read accordingly.

03

Auto mode observations

Availability depends on model, provider and policy. Some actions may resolve before classifier review. The app reports actual mode, action result and any startup diagnostic without fabricating classifier reasoning or promising the same outcome on every runtime.

04

Working-directory scope

acceptEdits automatically approves eligible operations in cwd or additionalDirectories. Protected paths and critical-path removals have additional rules. This app uses fixed local Read/Write operations and does not test destructive shell commands or protected system paths.

05

Bypass still has earlier checks

TypeScript requires allowDangerouslySkipPermissions true. Scoped denies and hooks still apply. The live scoped Edit deny protects only the disposable result file. SDK modes are permission policy, not an operating-system sandbox.

06

Subagent inheritance reference

Current docs inherit plan, acceptEdits, auto and bypass from the parent. A plan-mode parent remains restrictive even if a child definition requests acceptEdits; this differs from the supplied slide. Eligible overrides apply under default/dontAsk parents, and a child definition cannot enable bypass. This application launches no subagents.

07

Real review versus test automation

The web experiment waits for an actual Approve or Reject button decision. CLI automation requires --approve-plan; the live test harness uses an explicit review callback and labels it accordingly. Only approved review can request the mode switch.

08

Evidence and API cost

Nine actual SDK queries include a second model turn for the switching case. Each query has a $0.40 SDK budget threshold, not a prepaid cap. Credentials, dependencies, raw recordings and all teaching media stay outside Git.

09

Planning artifacts versus source edits

The SDK planning workflow may request a Markdown plan artifact under its private configuration directory. This classroom guard blocks every extra file, including those artifacts, and logs the hook rejection separately. Do not confuse that guard rejection with the callback denying result.txt in plan mode. The actual final plan text remains reviewable.
